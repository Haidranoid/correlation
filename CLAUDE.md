# Rules for this repository

## Tests of other people's ideas stay outside the repo

When a test comes from another person's idea (anything Brandon forwards from someone else: a message, a comment, a link, a repo), everything about it is stored outside this repository, in `/home/bhoult/programming/correlation-pending/`, mirroring the repo's paths:
- the plan and the experiment write-up (`experiments/…`);
- its code and outputs (`research/<topic>/`);
- its README rows and any notes.

It moves into the repo only when Brandon explicitly says to add it, after he has obtained that person's permission.

Until then:
- **Names:** no file in the repo names the person.
- **Ideas:** no file in the repo describes their idea or its results.
- **References:** repo files that need to refer to such a test call it something neutral, such as "an earlier test", without its file name, number, folder or topic.
- **READMEs:** the counts and indexes in `README.md`, `experiments/README.md` and `pendulum/README.md` cover only what is in the repo.

Published papers' authors are not covered by this rule. Brandon's own ideas aren't either.

`correlation-pending/README.md` lists what is held there and how to restore each item.
